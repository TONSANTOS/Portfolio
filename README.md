# 📌 Portfólio Pessoal

#### ✨ Bem-vindo ao meu portfólio! Um projeto moderno e responsivo desenvolvido com ReactJS e TailwindCSS, com suporte a dark/light mode, internacionalização (pt/en) e integração com WhatsApp e EmailJS para contato direto.

- ## 🚀 Tecnologias Utilizadas

    - **ReactJS** – Biblioteca JavaScript para construção de interfaces.

    - **TailwindCSS** – Framework CSS utilitário para estilização rápida e responsiva.

    - **React Responsive** – Adaptação de componentes para diferentes tamanhos de tela.

    - **React-i18next & i18next** – Internacionalização (pt/en) para suporte multilíngue.

    - **Context API** – Gerenciamento de estado para o tema dark/light mode.

    - **EmailJS** – Envio de e-mails diretamente do formulário de contato.

    - **React Icons** – Ícones modernos e consistentes.

- ## 🌟 Recursos

    - ✅ Design Responsivo – Adaptado para mobile, tablet e desktop usando React Responsive.
    - ✅ **Dark/Light Mode** – Alternância suave entre temas usando Context API.
    - ✅ **Tradução PT/EN** – Suporte a dois idiomas com React-i18next.
    - ✅ **Contato Direto** – Botão de WhatsApp e formulário com EmailJS.
    - ✅ **Estilização Moderna** – Utilizando TailwindCSS para um visual clean e profissional.


- ## 📥 Como Executar o Projeto

1. Clone o repositório

    ```
    git clone https://github.com/TONSANTOS/Portfolio
    ```

2. Instale as dependências

    ```
    npm install
    ```

3. Execute o projeto

    ```
    npm start
    ```

4. Acesse no navegador

   ```
    http://localhost:3000
    ```
